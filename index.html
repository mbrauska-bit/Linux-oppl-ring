Modul 1: Hva er Linux-terminalen?

Terminalen er et program der du skriver kommandoer for å styre datamaskinen. I stedet for å bruke musen kan du skrive hva datamaskinen skal gjøre.

Terminalen brukes ofte av IT-ansatte for å finne informasjon, administrere datamaskiner og løse problemer.

Slik åpner du terminalen

  1. Start Ubuntu.
  2. Trykk Ctrl + Alt + T.
  3. Terminalvinduet åpnes.
  4. Nå kan du skrive kommandoer.

Din første kommando: pwd

pwd betyr Print Working Directory. Den viser hvilken mappe du befinner deg i. For eksempel betyr /home/mark at du er i hjemmemappen til brukeren mark.

Prøv selv

Skriv pwd eller whoami.

Terminal - Ubuntu

whoami viser navnet på brukeren som er logget inn.

Tips: Linux skiller mellom store og små bokstaver. Skriv kommandoene nøyaktig.

Modul 2: Grunnleggende Linux-kommandoer

Linux har mange kommandoer. Her lærer du hvordan du kan se filer og mapper og rydde terminalvinduet.

Kommandoen ls

ls viser hvilke filer og mapper som finnes i mappen du står i.

Kommandoen ls -l

ls -l viser mer informasjon, for eksempel rettigheter, eier og størrelse. Bokstaven d først på en linje betyr at det er en mappe.

Kommandoen clear

clear rydder terminalvinduet. Den sletter ikke filer eller mapper.

Prøv selv

  1. Skriv ls og trykk Kjør.
  2. Skriv ls -l og sammenlign resultatet.
  3. Skriv clear for å tømme terminalen.
Terminal - Ubuntu

Tips: I en ekte Ubuntu-terminal kan du trykke pil opp for å hente fram tidligere kommandoer.

Quiz

Hva er forskjellen mellom ls og ls -l?

Vis svaret

ls viser fil- og mappenavn. ls -l viser også mer informasjon om dem.

Modul 3: Navigering mellom mapper

Filer i Linux er organisert i mapper. For å flytte deg mellom mapper bruker du kommandoen cd.

cd betyr Change Directory, altså å bytte mappe.

Gå inn i en mappe

Skriv cd Dokumenter for å gå inn i mappen Dokumenter.

Gå tilbake

cd .. går ett nivå opp i mappestrukturen. cd ~ går direkte til hjemmemappen.

Prøv selv

  1. Skriv cd Dokumenter.
  2. Skriv pwd for å se hvor du er.
  3. Skriv cd .. for å gå tilbake.
  4. Skriv cd ~ for å gå til hjemmemappen.
Terminal - Ubuntu

Tips: I ekte Ubuntu kan du bruke Tab-tasten for å fullføre mappenavn automatisk. Mappen kan hete Documents i stedet for Dokumenter.

Quiz

Hva er forskjellen mellom cd .. og cd ~?

Vis svaret

cd .. går ett nivå opp. cd ~ går til hjemmemappen.

Modul 4: Opprette filer og mapper

Du kan opprette nye filer og mapper direkte fra terminalen. Dette er nyttig når du skal organisere skolearbeid eller prosjekter.

Opprette en mappe med mkdir

mkdir betyr Make Directory. Kommandoen oppretter en ny mappe. For eksempel lager mkdir skole en mappe som heter skole.

Opprette en fil med touch

touch kan brukes til å opprette en tom fil. For eksempel lager touch notater.txt en tekstfil.

Prøv selv

  1. Skriv mkdir skole.
  2. Skriv ls for å se mappen.
  3. Skriv cd skole.
  4. Skriv touch notater.txt.
  5. Skriv ls for å se filen.
Terminal - Ubuntu

Tips: Bruk korte og tydelige navn på filer og mapper. Hvis en fil allerede finnes, vil touch normalt oppdatere tidsstempelet i stedet for å lage en ny fil.

Quiz

Hva er forskjellen mellom mkdir og touch?

Vis svaret

mkdir oppretter en mappe. touch kan opprette en tom fil.
